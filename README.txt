PC PLUS COMPUTING - WEBSITE IMAGES, SORTED BY PAGE
==================================================

HOW THIS IS ORGANISED
- Every page that has image cards has its own folder here.
- The folder path matches the page URL exactly.
     Folder:  services/macbook-repair/macbook-battery-replacement
     Page:    pcpluscomputing.com/services/macbook-repair/macbook-battery-replacement
- Every image is named by its keyword (SEO filename), e.g. macbook-battery-replacement.png
- The main landing-page images are in the "homepage" folder.
- A few images are shared by two pages (e.g. a repair image used on both the main
  category page and a sub-page). Those images appear in BOTH folders on purpose,
  so each page folder is complete on its own - you never have to hunt in another folder.

TO FIND IMAGES FOR A PAGE
- Open the folder whose path matches the page you are editing.
- Everything in it belongs on that page. Done.

QUICK REFERENCE
- INDEX.html  -> open in any browser: every page, its folder, and its images (with card titles) in one list.
- INDEX.csv   -> same as a spreadsheet (Page URL / Folder / Image filename / Card title).

TOTALS
- 72 pages, 862 image placements (844 unique images; 17 shared across two pages).

NOTE

  site pages you want folders for, send the list and they'll be added.
